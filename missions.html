HTML Forms

Learn how HTML forms collect information from users and how different form elements work together.

Study This Topic

HTML forms are used to collect information from users. A form can contain input fields, labels, buttons and other controls. 

<form>
    <label>Name</label>
    <input type="text">
    <button type="submit">Submit</button>
</form>

Key Concepts

<form> creates the form.
<input> collects user input.
<label> describes an input.
Buttons can submit form data.
